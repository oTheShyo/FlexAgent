# ZCode 对照差距 —— 工单索引

来源：ZCode（zcode.z.ai / zai-org/ZCode）与本仓库的功能对照分析。  
用法：**每个执行会话领取一张工单**，只做该工单并在完成后勾掉验收项。

## 规则

- 一票一文件，按依赖序编号；`Blocked by` 全部完成才能领取（frontier）。
- 状态统一 `ready-for-agent`；完成后把状态改为 `done` 并勾选验收项。
- 工单内避免写死代码路径（会过期），以行为验收为准。
